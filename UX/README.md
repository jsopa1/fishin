# UX wireframes

Reference wireframes for [`docs/v4_ux_goal_loop_spec.md`](../docs/v4_ux_goal_loop_spec.md)
(the approved spec) and [`docs/v4_ux_redesign_plan.md`](../docs/v4_ux_redesign_plan.md).

Navigation: the fish logo at the top always returns to Recommended; the
bottom nav is last-visited spot / Explore (map pin) / Profile.

1. `01_recommended.png` — Recommended screen (Saved Spots + Recommended Spots)
2. `02_spot_detail.png` — Spot Detail (Active / Inactive fish, stocking, regulations, advisory)
3. `03_fish_detail.png` — Fish Detail (activity, habitat, recommended bait)
4. `04_profile.png` — Profile (preferences, settings)
5. `05_explore.png` — Explore (Map | List toggle, then filters, then map or ranked list)
