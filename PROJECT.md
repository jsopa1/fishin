# Project

## Current Objective

Determine whether publicly available data can support a useful, validated fishing-conditions prediction.

## Current Phase

V0 — Prediction Feasibility

## Critical Hypothesis

Weather, seasonality, time, location, species, and environmental conditions contain enough signal to predict fishing activity better than a reasonable baseline. This is a hypothesis, not an established fact.

## Initial Constraints

* $0 budget
* Free APIs where possible
* Public/open datasets
* Open-source software
* OpenHands for AI-assisted development
* Minimize infrastructure
* No unnecessary paid services or complexity

## V0 Success Criteria

1. Find usable fishing observations.
2. Find usable historical environmental/weather data.
3. Join the datasets where possible.
4. Define a measurable fishing outcome.
5. Establish a baseline.
6. Build candidate predictive models.
7. Evaluate against held-out historical data.
8. Determine whether meaningful predictive signal exists.

## Current Rule

Do not build the polished application until the underlying prediction has demonstrated useful predictive signal.
